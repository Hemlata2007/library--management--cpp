# Library Management System (C++)

A simple console-based Library Management System built in C++.

## Features
- Add a new book (ID, Title, Author)
- View all books currently in the library

## Concepts Used
- Structures (`struct`)
- STL Vectors (`vector<Book>`)
- Functions
- Menu-driven console interface (`switch` statement)

## How to Compile and Run
```bash
g++ library.cpp -o library
./library
```

## Tech
- Language: C++
- Compiler: g++ (tested on Kali Linux)
